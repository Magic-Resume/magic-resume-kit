# @magic-resume-kit/resume-schema

Validated resume data contracts, template IDs and JSON Schema.

```sh
npm install @magic-resume-kit/resume-schema
```

MIT licensed. See the [workspace guide](https://github.com/Magic-Resume/magic-resume-kit) for development and release instructions.

## Public distribution

Install `@magic-resume-kit/resume-schema` from the public [npm registry](https://www.npmjs.com/package/@magic-resume-kit/resume-schema). No GitHub Packages token or private registry configuration is required. The package source and release workflow live in [Magic Resume Kit](https://github.com/Magic-Resume/magic-resume-kit).

See the [consumer integration guide](https://github.com/Magic-Resume/magic-resume-kit/blob/main/docs/consumer-migration.md) for host requirements and the [release guide](https://github.com/Magic-Resume/magic-resume-kit/blob/main/docs/releasing.md) for versioning and publication.
